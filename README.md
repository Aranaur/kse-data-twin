# Цифровий двійник у залі

Учасники лекції оцінюють теми на телефоні, застосунок знаходить кожному найближчу за смаками людину за косинусною подібністю. Застосунок написаний на Shiny for Python.

Адреси:

- `/` — сторінка для телефона
- `/?paper=1` — внесення паперових анкет з одного пристрою
- `/?screen=1&key=...` — карта для екрана з кнопками
- `/?screen=1&key=...&names=1` — те саме зі списком імен, лише для ведучого

Дані зберігаються тільки в пам'яті процесу й зникають після очищення або перезапуску.

Запуск локально: `uv run shiny run app.py --port 7861`
